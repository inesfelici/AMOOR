Importar documents

A-MOOR registra l’origen del contingut importat perquè després pugues eliminar un document junt amb les dades que només provenien d’ell.

Referències i idees

Accepta anys numèrics i «s.f.», títols amb punts, interrogacions o exclamacions, autors amb diverses referències, «AUTORS SENSE REFERÈNCIA BIBLIOGRÀFICA» i ignora «DUBTES PER REVISAR».

Com ha de ser el document?
Format bàsic
Autor (Any). Títol. Editorial. Idea: Primera idea associada a l’autor. Idea: Segona idea associada a l’autor.

Regles: cada referència ha d’anar en una línia pròpia. Si un autor té diverses referències, posa primer totes les referències i després les línies Idea:. No uses vinyetes ni numeració davant de les referències o les idees.

Es poden usar anys com 1964 o s.f.. Els títols i editorials es mantenen en l’idioma original.

Per a autors dels quals només tens idees, crea al final l’encapçalament exacte AUTORS SENSE REFERÈNCIA BIBLIOGRÀFICA, escriu el nom de l’autor en una línia i després les seues línies Idea:.

AUTORS SENSE REFERÈNCIA BIBLIOGRÀFICA Zoltán Kodály Idea: El repertori popular és una base potent d’aprenentatge musical.

Si necessites deixar observacions que no s’han d’importar, usa l’encapçalament DUBTES PER REVISAR. A-MOOR ignorarà tot el que aparega després.

Pots copiar aquestes instruccions i demanar a una persona o a una IA que adapte el teu document a aquest format.

Format: Autor (Any). Títol. Editorial. + línies «Idea: ...»

Altres

Cada targeta pot ser unidireccional o bidireccional. Pots importar tot el document a una carpeta o indicar «Carpeta: ...» dins del document.

Com ha de ser el document?
Una targeta
Anvers: Pregunta o contingut de l’anvers Revers: Resposta o contingut del revers Mode: anvers-revers

Mode: anvers-revers pregunta sempre l’anvers i espera el revers. Usa Mode: bidireccional quan vulgues que A-MOOR puga preguntar en els dos sentits.

Carpeta: Frases Anvers: Frase de Manuel Romero Revers: La música és essencial per a viure Mode: bidireccional

Per a una resposta amb diverses parts, continua escrivint-les en les línies següents després de Revers:.

Carpeta: Definicions Anvers: Qui ha escrit les definicions de "llenguatge"? Revers: AVL — vocabulari... Hemsy de Gainza — llenguatge tan natural... Mode: anvers-revers

Carpeta: és opcional. Si no apareix, A-MOOR usarà la carpeta per defecte seleccionada abans de pujar el fitxer.
